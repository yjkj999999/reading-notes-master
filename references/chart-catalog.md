## 2. 通用设计规范

- **色彩**：图表仅用「主题色 + 强调色 1 种 + 灰阶」，禁止彩虹配色。
- **字号**：图内文字 ≥14pt（缩放后仍可读）；节点标题 20–24pt。
- **留白**：组件四周 ≥32pt；同页多组件间距 ≥48pt。
- **数据诚信**：数据图表必须标注出处（书名+章节/页码）；金融走势注明区间。
- **图标**：线性图标统一描边粗细(2px)；不混用拟物与扁平。
- **编号语义**：步骤用①②③/01–05；推荐序用 NO1/NO2；篇章用 PART 01。

## 3. 选型决策树

```
要表达什么？
├─ 时间/演进 ─→ 少节点(≤6) 用时间线；多阶段(≥7) 用阶段带
├─ 对照 ─→ 两方对比用双栏；多维归类用象限
├─ 结构/原理 ─→ 因果链用框架模型图；全书收纳用一页纸表格
├─ 清单/步骤 ─→ ≤5 项用编号卡片；>5 项分组后多卡并列
├─ 数据 ─→ 走势用折线+阶段带叠加；构成用条形（避免 3D 饼图）
└─ 复盘/总结 ─→ 思维导图（收尾页固定件）
```

## 4. 图文配比速查

| 页型 | 文字 | 图表/图像 |
|---|---|---|
| 封面/篇章页 | ≤20 字 | 整页视觉（大图或主题色块+大字） |
| 内容页 | 80–150 字 | 1 个主组件 + 图标点缀 |
| 数据页 | ≤60 字 | 图表占 70% 版面 |
| 金句页 | 1–2 句 | 超大引号装饰 |
| 收尾页 | ≤100 字 | 思维导图占 60% 版面 |

> 语料实测图片密度 0.07–1.0、多数 >0.6 —— 任何内容页不得纯文字满版。
