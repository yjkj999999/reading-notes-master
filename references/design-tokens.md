# 设计令牌 Design Tokens（出版级质感 v2）

> 来源：awesome-design-md 双规范（Notion 暖中性系统 × Claude 羊皮纸画布）× 31 份语料实测数据。
> 本文件是**质感层令牌**（与书籍类型无关，所有笔记通用）；书籍主题色选型见 `design-system.md` §3.2。
> 模板 `templates/reading-notes-template.html` v2.0 的 `:root` 已内置全部令牌，换肤只改主题色三变量。

---

## 1. Visual Theme（视觉主题）

- **暖纸出版感**：白底主导（占比 ≥55%），暖白 `#F7F5F2` 分区交替，Ivory `#FAF9F5` 做卡片底。
- **暖近黑墨色**：正文用 `rgba(30,26,22,.95)`，禁纯黑 `#000`、禁冷蓝灰（`#6B7280` 系）。
- **一页一义的主题色**：主题色只出现在标题带/篇章页/图表主线/编号/金句引号；每页饱和色 ≤1 族。
- **质感靠"耳语"**：1px 低透明度边框 + 多层柔影（单层 ≤5%），不靠粗边框重投影。
- **留白即排版**：组件间距 ≥24px，宁可删内容不可挤压。

## 2. Color Palette & Roles（色板与角色）

| Token | 值 | 角色 | 占比 |
|---|---|---|---|
| `--c-ink` | `rgba(30,26,22,.95)` | 正文/标题墨色 | 主要文本 |
| `--c-ink-2` | `rgba(30,26,22,.60)` | 次级说明、页眉页脚 | 辅助 |
| `--c-ink-3` | `rgba(30,26,22,.38)` | 弱化注脚、页码 | 点缀 |
| `--c-bg` | `#FFFFFF` | 页面底色 | ≥55% |
| `--c-bg-alt` | `#F7F5F2` | 暖纸交替分区 | 交替页 |
| `--c-bg-ivory` | `#FAF9F5` | 背书卡/引用卡底 | 卡片 |
| `--c-line` | `rgba(30,26,22,.10)` | 耳语边框/分隔线 | 全局 |
| `--c-line-strong` | `rgba(30,26,22,.16)` | 时间线轨道/分组边 | 局部 |
| `--c-primary` | 查 design-system.md §3.2 | 标题带/篇章页/图表主线 | ≤1 族/页 |
| `--c-primary-soft` | 主题色 8% 透明 | 徽章/卡片衬底 | 点缀 |
| `--c-accent` | 主题伴生强调色 | 项目符/连线/峰值 | 点缀 |

**禁止**：纯黑 `#000` 文本、纯白 `#FFF` 以外的冷灰底、每页 >2 族饱和色、荧光色。

## 3. Typography Rules（字体排印）

- **四字重体系**：`400` 正文阅读 / `500` 小标题·衬线金句 / `600` kicker·徽章·强调 / `700` 大标题宣告。上限 700，不用 800/900。
- **字号阶梯**（16:9 实测锚点）：封面 64–120 / 篇章 42–56 / 页标 34–40 / 副标 26–32 / 正文 20–24 / 注释 14–18。
- **负字距渐进**（展示级压缩，仅标题）：

| 字号 | 字距 |
|---|---|
| ≥96px | −2 ~ −3px |
| 64–96px | −1.5px |
| 40–56px | −0.5 ~ −1px |
| 26–32px | −0.25px |
| 正文 20–24px | 0（禁负字距） |
| kicker/眉标 | 正向 +3 ~ +8px |

- **行高随字号收紧**：展示级 1.08–1.15 / 页标题 1.2–1.25 / 正文 1.60–1.65（文学性）/ 注释 1.5。
- **衬线选项**：人文类书籍的封面、金句页可用 `Georgia + Songti SC`，字重 500，全篇占比 ≤10%。
- **数字**：`font-variant-numeric: lining-nums`（等高数字，年份/页码更齐整）。

## 4. Component Stylings（组件样式）

| 组件 | 规格 |
|---|---|
| 卡片 `.card` | 白底 + 耳语边框 + `radius 12` + `sh-2` 柔影 + 主题色条 44×5px |
| 背书卡 `.quote-card` | Ivory 底 + 耳语边框 + `radius 12` + `sh-1` |
| 双栏对比 `.duel` | `radius 16` + `sh-1` + 内部虚线分隔 |
| 药丸徽章 `.pill` | 主题色 8% 底 + `9999px` + 字重 600 + 字距 +1px |
| 时间线 `.tl` | 轨道 `--c-line-strong`，节点主题色 6px 环 |
| 金句页 `.golden` | 衬线 500、150px 引号（主题色 16% 透明）、行高 1.65 |
| 页眉页脚 `.hd/.ft` | 耳语边框、600/400、字距 +2px |
| 篇章页 `.part` | 主题色整页 + 白字 + 左竖线引言 |

## 5. Layout Principles（版式原则）

- 版心 1280×720 固定；页边距 56px（上下）× 72px（左右）；页眉 52px、页脚 44px。
- **白/暖白交替**：内容页每 2–3 页切换 `.alt`（暖纸底），避免长篇白底单调，暗示章节节奏。
- 垂直节奏：kicker → 标题 → rule 色条 → 组件，间距 10/8/22/26/32px 阶梯。
- 单页 ≤150 字正文、≤2 个组件、≥1 个视觉锚点。
- 网格严格对齐：同排卡片等高，标题基线跨页一致。

## 6. Depth & Elevation（深度与阴影）

- **单层阴影透明度 ≤0.05**，色调暖：`rgba(28,25,23,…)`。
- 三级柔影栈：

| 级别 | 用途 | 值 |
|---|---|---|
| `--sh-1` | 浮起卡片 | `0 1px 2px .04` |
| `--sh-2` | 标准卡片 | `0 1px 3px .04` + `0 4px 12px .04` |
| `--sh-3` | 浮层/焦点 | `0 1px 2px .03` + `0 4px 12px .03` + `0 12px 32px .04` |

- **环形替代方案**（Claude 式）：浅色卡可用 `box-shadow:0 0 0 1px var(--c-line)` 代替 1px border，观感更轻。
- **禁止**：重黑投影（`rgba(0,0,0,.3+)`，仅限工作区预览底）、发光效果、多层内阴影。

## 7. Do's and Don'ts（护栏）

**Do**：暖中性墨色 / 耳语边框 / 三级柔影 / 标题负字距渐进 / 四字重（≤700）/ 暖纸分区交替 / 药丸徽章 / 衬线金句（500）/ 大留白 / lining-nums。

**Don't**：
- 纯黑 `#000` 文本、冷灰蓝底、正文用负字距
- 粗边框（≥2px）+ 重投影组合
- 衬线加粗（衬线只用 400/500）
- 圆角 <8px 的锐角卡片
- 每页 >2 族饱和色；主题色当正文色用
- 居中排长段正文（正文一律左对齐）

## 8. Responsive / Export Behavior（响应与导出）

- 版心固定 1280×720，`@page{size:1280px 720px;margin:0}`。
- 打印/导出：去工作区底色、去阴影、每页强制分页。
- 窄屏预览：`scale(.62)` 适配。
- PDF/PPTX/长图管线见 `templates/output-pipelines.md`。
