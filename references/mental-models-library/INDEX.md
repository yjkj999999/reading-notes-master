# 思维模型库 INDEX（reading-notes-master v2.5 构图建模层）

> 全量收录《万物皆模型——100 个思维模型》（103 页，每模型一页：中文定义+模型结构图），
> 100/100 模型结构化入库（见 `models-catalog.md`）。
> 定位：**图形图表图例图案的模型库**——笔记内容命中某思维模型的信号时，
> 直接调用该模型经过验证的标准图型构图，而非从零发明图示。

## 一、四步用法（构图建模）

```
① 信号扫描：逐章扫描内容，对照 models-catalog.md 的"内容信号词"列
        ↓
② 模型匹配：命中 → 记下（模型编号, 图型族）；一章可命中多个，取最强 1-2 个
        ↓
③ 构图调用：按模型的"构图要点"落图型——同族模型共用构图法（10 族模板见 models-catalog.md 总表）
        ↓
④ 落地检查：过"图型-内容契约"（见下），不合格回 ② 重匹配
```

**图型-内容契约**（每个模型图必须满足）：
- 图型要素与模型定义一一对应（如飞轮必须有"推力段→自持段"，缺一即错）；
- 图的标注文字 ≤12 字/节点，数值必须来自原文；
- 图能独立表意：遮住章节标题，图仍讲得通；
- 与页面文字预算兼容：图注 ≤30 字，不重复正文。

## 三、文生图 Prompt 构建规范（v2.5 新增）

### 适用边界（先读这个）
- **器型/结构化图示**（矩阵、循环、曲线、树形）→ 一律用 HTML/SVG/脚本绘制（chart-catalog / graphics-toolchain / clip-chart），**不作文生图**——文字标注精度不可丢。
- **文生图只做四类氛围资产**：封面主视觉、hero 整页意象图、金句页背景、篇章过渡页氛围图。
- 无可用图像生成工具时 → 降级为"几何氛围图"（SVG 大色块+主题色渐变+器型剪影），不阻塞交付。

### Prompt 五要素公式
```
[主体意象] + [图型几何] + [风格令牌] + [主题色] + [负面约束]
```
1. **主体意象**（从模型库取）：用模型的视觉意象而非抽象概念。
   如 #43 蝴蝶效应→"一只蝴蝶翅膀的气流纹路逐渐演变为远处的风暴"；
   #49 冰山→"一座冰山，水面上小下部巨大，水面线清晰"；
   #75 飞轮→"一个沉重的金属巨轮正在被推动，动量渐起"。
   → 每模型的意象词见表内"构图要点"，取其第一短语。
2. **图型几何**（从图型族取构图指令）：
   `minimalist centered composition / strong diagonal / symmetrical radial / horizontal band / layered depth`
3. **风格令牌**（reading-notes 出版级质感，写死）：
   `flat vector illustration, warm paper background #F7F5F2, ink #1A1A1A, soft 3-level shadows, whisper-thin borders, no gradients except one accent, editorial print aesthetic, Notion-meets-Stripe style`
4. **主题色**（Step 0《设计决策单》的主色 hex 代入）：
   `accent color #XXXXXX used sparingly`
5. **负面约束**（写死）：
   `no text, no letters, no words, no watermark, no logo, no 3D render, no photorealistic, no clutter, no stock-photo people`

### 各族 Prompt 模板（套用即可）

| 图型族 | 模板主干 |
|---|---|
| PY 层级 | `layered pyramid silhouette, {主题} growing from wide base to sharp peak, one accent layer in {主色}` |
| MX 矩阵 | `abstract 2x2 grid of soft rounded squares, one quadrant filled with {主色}, others whisper-gray` |
| CY 循环 | `circular arrow loop made of thin ink line, 4 nodes as small circles, {主色} node highlighted` |
| CV 曲线 | `single elegant curve on empty axes, key inflection point marked with a small {主色} dot, lots of negative space` |
| FL 流程 | `horizontal chain of 4-5 minimal nodes connected by thin arrows, last node in {主色}` |
| CP 对比 | `two mirrored shapes facing each other across a thin vertical divider, one in ink one in {主色}` |
| NW 网络 | `sparse network of small dots connected by hairline links, one cluster highlighted in {主色}` |
| MC 机制 | `a lever/fulcrum/magnifier minimal diagram in flat vector, {主色} on the moving part` |
| DK 决策 | `a path splitting into two branches, one branch fading to gray one in {主色}` |
| TR 树形 | `a tree branching from a single root into MECE branches, one branch in {主色}` |

### 尺寸与用量纪律
- 封面 1600×900，hero 图 1200×800，金句背景 1600×900（高斯模糊 8px 后压字）；
- 每本笔记文生图 ≤5 张（封面 1 + hero ≤2 + 金句背景 ≤2），其余全部器型化；
- 所有生成图记入 `assets/generated/` 并在交付说明中标注生成工具与 prompt 摘要。

| 步骤 | 模型库接入 |
