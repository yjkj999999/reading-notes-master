## 1. 三条铁律（Chart-First 宪法）

1. **先图后文**：每页动笔前先问"这页信息最贴 §2 映射表的哪种器型？"——选得出器型，页面即按器型骨架写；选不出（如纯故事、纯情绪）才允许 1 段短文 + 1 张 hero 图。
2. **文字预算**（单页硬上限，超出即砍文保图）：
   - 图解页（一个器型撑满）≤ **120 字**；卡片页（器型+注解）≤ **150 字**；
   - **数字必须可视化**：任何带数字的结论 → 大数字卡（stat）/图表标注，禁止数字埋进段落；
   - 文字墙封禁：单页 >300 字 = 违规页（对照《考试脑科学》1,025c/页）。
3. **图解页配比**：内容页中"图表主导页"（一个器型占版面 ≥60%）占比 **≥60%**——对齐冠军语料 73%–98% 区间的下沿；每章至少 **2 种不同器型**，全书至少 **6 种**。

## 2. 文字→图表自动映射表（核心资产）

拿到一章要点后，逐条扫描下列信号词，命中即转译为对应器型：

| 优先级 | 文本信号（实测命中） | 转译器型 | 版面预算 | 实测样本 |
|---|---|---|---|---|
| ★★★★★ | 年份、"阶段/时期/演进/历程"（2,405） | **时间线 / 阶段带** | 横轴占版面 70% | 华为 1987–2019 五阶段；美股70年八段带 |
| ★★★★★ | "第一/步骤/①②/NO.x"（1,159） | **编号卡 / 流程链** | 2×3 或 1×5 网格 | 丰田步骤①–⑤；推荐理由 NO1–5 |
| ★★★★ | "公式/＝/回报率"（607） | **公式卡 / 大数字卡** | 公式行 48–60px + stat 60px | 公司理财 NPV/IRR 卡 |
| ★★★★ | "框架/模型/体系/要素"（606） | **框架模型图 / 中心辐射** | 3–5 节点 + 连线标签 | 金线原理三角；BLM/DSTE 链 |
| ★★★ | "流程/闭环/迭代"（310） | **横向流程链 / 循环图** | 4–6 节点箭头链 | 华为 DSTE；复盘四步循环 |
| ★★★ | "清单/法则/原则/戒律"（214） | **图标网格 / mini 竖排小卡** | 每条 ≤12 字+图标 | 人生护城河十条守则 |
| ★★★ | "VS/对比/而非/差异"（198） | **双栏对比 / duel VS 徽章** | 中缝分隔，左右同构 | 自洽"理想\|现实"；丰田"PPT\|一页纸" |
| ★★ | "漏斗/转化/筛选"（165） | **漏斗图** | 3–5 层递减色带 | 营销转化链 |
| ★★ | "占比/构成/份额/%"（162） | **环形图 / 条形图** | SVG 环形 + 图例 | 哈克曼 60·30·10 精力法则 |
| ★★ | "金字塔/层级/自上而下"（134） | **金字塔图** | 3–4 层梯形 | 金字塔原理 |
| ★ | "矩阵/象限/二维"（30） | **2×2 象限** | 轴短语化+四格标签 | 走出思维泥潭 |
| ★ | "表格/九宫格/看板"（7） | **一页纸表格** | 整页一表收纳全书 | 丰田 Excel1 3×3 |

**转译口诀**：见"时间"画轴线，见"编号"拆卡片，见"数字"放大数，见"框架"连节点，
见"对比"劈两栏，见"占比"转圆环，见"层级"叠金字塔，见"清单"铺图标，见"漏斗"收梯形。
**同一章内器型不重复出现相邻两页**（防视觉疲劳）；器型库不够用时回退 hero 整页图 + 图注药丸。

## 3. 全书页面配比公式（Chart-First 版）

```
封面(1) + 书档速览 stat卡(1) + 作者 hero(1) + [背书/权威 hero(0–1)] + 互动测试(0–1)
+ 为什么读它(1，编号卡) + 目录(1) + [篇章分隔：chap 药丸列章名(每 PART 1)]
+ 内容页×n  ← 其中 器型图解页:hero图文页 ≈ 6:4，且每 2–3 页切 .alt
+ 金句页(2–3，衬线大引号) + 思维导图收尾(1) + 封底(1)
```

- 内容页每页必须携带 **≥1 个视觉锚点**（器型 / 大数字 / 原书插图 / SVG 图），0 锚点页禁发。
- 精华版总页数不变（30–60 页），但页数不够时**先砍文字页、不砍器型页**。

## 4. 动笔三问（选型决策树 v2，替代逐组件查表）

1. **这页有数字吗？** → 有：趋势→折线+阶段带；构成→环形/条形；单值→stat 大数字卡。
2. **这页有结构吗？** → 有：时序→时间线；因果→框架图；分层→金字塔；归类→象限；对照→双栏/duel。
3. **这页只有故事/情绪吗？** → 是：hero 整页图 + ≤80 字叙事 + 图注药丸。

三问皆"否且无图可用"→ 该内容降级并入相邻页，不单独立页。

## 5. 反面清单（文字墙特征，出现即返工）

- 单页 >300 字且无器型/图像（考试脑科学式失败）；
- 数字埋在段落里未做可视化；
- 连续 2 页同款器型（6 张编号卡排排坐）；
- "图表页"实为文字换皮：只有标题+长句，无网格/轴线/节点；
- 金句页塞满解释文字（金句页只留 1–2 句 + 装饰引号）。
