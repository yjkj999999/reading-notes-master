# 咨询级页面工艺知识库（consulting-craft）

> **v2.2 新增**。提炼自开源项目 consulting-report-forge v1.8.0（Apache-2.0，作者 ZeroxZhang），
> 按 reading-notes-master 语境重组。定位：把"图表主导"的页面再往前推一步——**图表不仅要多，
> 还要像咨询顾问的 slide 一样严谨**：标题是判断、证据有契约、图型有语义、密度有预算、验收有门禁。
>
> **何时读**：Step 3 转译与 Step 4 排页时，凡涉及**论证型内容页**（商业书/方法论书/数据复盘/行业分析类）
> 就按本文件升级页面工艺；纯故事/情绪页仍走 hero 图文路线，不受此约束。

## §1 叙事弧线：先答案，后表达

每一份笔记先选一条**叙事弧线**（书本身在回答哪类问题），再决定页面序列。四条弧线（每条五个站位）：

| 弧线 | 五个站位 | 适合的书型 |
|---|---|---|
| **机会→选择** opportunity-to-choice | 决策问题 → 机会规模 → 竞争约束 → 可选路径 → 推荐门槛 | 商业决策、战略、增长类 |
| **问题→修复** problem-to-fix | 目标现状 → 症状 → 根因 → 方案取舍 → 路线图 | 管理、效率、个人提升类 |
| **不确定→下注** uncertainty-to-bet | 不确定性 → 暴露 → 情景差异 → 不后悔动作 → 治理监测 | 投资、宏观、风险类 |
| **证据→观点** evidence-to-view | 口径定义 → 事实模式 → 机制异质性 → 反证边界 → 含义 | 研究、社科、数据复盘类 |

**两条硬纪律**：
1. **adds 纪律**：每一页必须能回答"读者比上一页**多知道什么**"。答不出的页砍掉或合并——没有信息增量的页面是装饰，不是叙事。
2. **主张-证据对账**：全书的**核心答案**必须被某一页明确承担（该页标题就是答案本身），其余页是它的证据链或边界条件。收尾页不做泛化总结。

## §2 标题纪律：标题是判断，不是目录

- **弱标题**（禁用）："市场概览" / "AI 的影响" / "第三章要点" / "下一步建议"——只是目录词，不含判断。
- **合格标题** = **可验证的判断句**，含主语、方向、量级或条件。对照示例：
  - 弱："市场概览" → 合格："市场年增 12%，但增量集中在低端价位"
  - 弱："AI 的影响" → 合格："AI 替代的是流程环节，不是判断环节"
  - 弱："时间管理建议" → 合格："先砍任务，再谈效率——排序收益大于执行收益"
- **强词清单**（出现即需更强证据支撑，否则降级为限定表述）：
  `驱动、导致、主要、唯一、显著、确定、最优、必然、全面、行业平均`
  - 处理方式：拿不出硬证据就把"驱动"降为"相关"，"主要"降为"常见"，"唯一"降为"少见"，或补上量化限定（"在样本期内""对价格敏感人群"）。

## §3 页面角色表：每页有且只有一个角色

| 角色 | 读者需要获得什么 | 不能替代为 |
|---|---|---|
| cover | 知道这是什么、为什么值得读 | 内页内容的预告堆砌 |
| section（篇章页） | 知道本篇章要回答的问题 | 一句话金句撑场 |
| analysis | 一个论点 + 支撑它的证据 | 观点罗列无证据 |
| decision / takeaway | 一个明确取舍或判断 | "各有优劣，视情况而定" |
| action | 可执行的具体动作（谁/做什么/到什么程度） | 愿望清单（"要重视""要加强"） |
| risk | 一个具体风险的边界条件与应对信号 | 末页泛化免责声明 |
| appendix | 可查值的原始数据 | 正文论点的复制 |
| close | 记住全书唯一的那个核心答案 | 把所有章节再列一遍 |

## §4 单页五区骨架 + 密度三档 + 收束唯一

**每个论证页自上而下五区**（骨架恒定，可省区不可乱序）：

```
① 结论型标题（判断句，全页最大字级）
② 主展品（1 个占版面 ≥60% 的图/表/图示）
③ 支持证据 + 关键限定（证据必须与标题判断同向；限定写明适用边界）
④ 含义或行动（"所以读者该改变什么认知/动作"）
⑤ 来源（原书章节/数据出处，安全区固定）
```

**三条重点感测量**：
1. **收束唯一**：每页恰 **1 个 takeaway 节点**。分工固定——标题给判断、副标题给口径、正文给证明、收束给结论；**四处不能都在下判断**（判断只出现在标题+收束，其余是证明）。
2. **字号次序**：标题必须是全页最大字级；收束字号 < 标题 > 正文；违者页面层级失守。
3. **声明画面一致**：标题声称的重点，必须是页面的**视觉第一落点**（最大的图、最粗的数字）。标题说 A 而画面最大的是 B，即返工。

**密度三档**（按**证据职责簇**计数，不按卡片数量）：

| 档位 | 定义 | 适用 |
|---|---|---|
| dense | 主展品 + ≥2 种不同证据职责（如对比+机制）+ 含义限定 | 核心论证页 |
| balanced | 主展品 + 1 个支持单元 | 常规内容页 |
| sparse | 1 个关键证据 + 解释的停顿 | 金句页/转折页 |

**留白纪律**：留白必须有**阅读用途**——分组、聚焦、比较间隙、节奏停顿、来源安全区。逐区域记录"位置+功能+依据"；大面积无功能留白 = Major 问题。85%/60% 等填充率是**诊断阈值**（触发检查），不是自动通过线。

## §5 关系→图型选型表 + 数据契约

**选型程序**：先问"这组数据的关系是什么"，再选图型；数据装不进契约就换图型或换数据，**不许削足适履改数据迁就图**。

| 数据关系 | 图型 | 数据契约（最低要求） |
|---|---|---|
| 比较排名 | 排序条形 / 哑铃 / 斜率图 | 类目字段 + 数值字段 |
| 趋势 | 时间序列线/柱 | 时间连续且有序 + 数值（缺口须标示，不许平滑造假） |
| 构成 | 份额条 / 堆叠 / mekko | **互斥可加** + 整体定义明确；不满足则禁用饼图/份额图 |
| 分布 | 直方图 / 箱线 | 分箱区间 + 频数；**只报均值=违规**（掩盖分布） |
| 相关 | 散点 / 热力 | 两两成对观测；相关≠因果，标题禁用"导致" |
| 目标对比 | 子弹图 / KPI 卡 | 实际值 + 单位 + 期间；**无目标值不虚构目标** |
| 桥接增减 | 瀑布图 | 见 §7 对账合同 |
| 流程流量 | 桑基 / 流程图 / 泳道 | 每边含义明确；流量守恒或声明损耗 |
| 机制因果 | 机制图（diagram.mechanism） | 每条边标证据状态（见 §8） |
| 精确查值 | 表格 | 数值优先给表，"精确比直觉重要"时禁用图形化 |

## §6 反模式红线清单（出现即返工）

1. 伪 3D 定量图（透视扭曲面积）。
2. 气泡按**半径**映射数值（必须按**面积**）。
3. 双轴图暗示伪相关（两轴单位不同的线图叠加）。
4. 不可加数据画成份额/饼图（如"满意度"平均分）。
5. 雷达图维度>5 或各轴尺度不可比。
6. 平滑曲线伪造连续（稀疏点必须用散点/柱）。
7. 等宽箭头暗示定量或因果（流量不等却画等宽桑基）。
8. 0–100% 仪表盘滥用（非百分比概念强行套仪表盘）。
9. 只报均值、不给分布（"平均收入 2 万"掩盖中位数）。
10. 截轴不声明（柱状图 y 轴不从 0 起且无标注）。
11. 关键信息依赖悬停才能看到（静态导出即失效）。
12. 纯装饰色条数字卡（颜色不编码任何信息还抢注意力）。
13. 力导向图的距离被解读为业务距离。

## §7 瀑布对账合同（数据最严图型，红线 9 条）

- **缺失 ≠ 0**：'' / `--` / `null` / `待补` 一律解析为**缺失**，绝不代入 0 参与计算。
- **不自动平账**：增量合计与净变化超容差 → 报 `not_reconciled`，差额原文展示，**不许塞平衡项抹平**。
- **残差只在你承认时画**：显式声明 `residual: explicit` 时才允许残差节点，且只允许出现在桥接段与终点之间。
- 汇总行/重复类目必须剔除，否则阻断。
- **零绝不印成"0"**：印 `<0.005`（或对应精度），防止读者误读为精确零。
- 不推断指标类型；不画破轴。
- 节点 ≤18（实际贡献项 ≤16）。
- **不声称因果**：瀑布是描述性分解，标题禁写"导致"。
- rate 模式两期都必须有分母，单位是**百分点 pp 不是 %**。
- 展示语法：净变化 `+300`；缺失 `—`；pp/%不混用。

## §8 图示语义五合同（画关系图必须签的合同）

| 图示类型 | 合同 |
|---|---|
| **机制图** | 每条边必须有 label + 证据状态：`supported`（书中有实证）/ `hypothesis`（作者假说）/ `unknown`（未说明）；回路边标 `feedback: true` |
| **流程图** | 边标注 role：`sequence`（先后）/ `transfer`（转移物） |
| **泳道图** | 三要素齐备：lane（谁负责）+ stage（阶段）+ handoff（交接点显式标出） |
| **层级图** | 边标注 relation：`contains`（包含）/ `depends_on`（依赖）/ `requires`；**唯一包含根**；禁止用依赖边冒充包含边 |
| **条件/决策图** | decision 节点 + outcome 节点分明；分支概率合计 = 1（或声明为示意） |

## §9 模块填充协议（P-D-F-X-V）+ 假修复禁令

- **P 排版前预防**：P1 逐模块统计内容量选布局；P2 选弹性元素（先想好哪里可伸缩）；P3 固定锚点（标题/来源/收束位置恒定）；P4 同排模块填充率差 **≤15pp**。
- **D 逐区域检测**：D1 找最大空白带；D2 三带检查（标题带/内容带/来源带各就各位）；D3 查裁切与溢出。
- **F 有界修复阶梯**（逐级用，不许跳级）：
  - L1 间距（行距/边距微调）→ L2 尺寸（**先放大弹性图形**，不是先缩字号）→ L3 结构（横纵重组/分栏/换布局）→ L4 表达（改关键数字卡/真实引言，**不是**注水文字）。
- **X 假修复禁令 8 条**（出现即返工）：偷改固定模块尺寸 / 内容移出安全区 / 加空行凑满 / 打乱字号层级 / 拉伸图片变形 / 空框填白造占位 / **编造数据充数** / 同排模块字号不一致。
- **V 复检**：修复后重跑 D 检测，确认无新问题。

## §10 容量先约束后填充（16:9 硬网格）

选布局**那一刻**就判断装不装得下；**缩字号是失守后的补救，不是设计**。

- 画幅 1280×720；版心 1200×662（内边距 上32/左右40/下26）。
- 12×6 网格：12 栏（栏宽 89px + 12px 沟槽）、6 行（行高 71px + 12px 沟槽）。
- 标题带固定 128px，正文起点恒定 **y=160**；来源带 48px 贴底。
- 跨行容量可预计算：如占 3 行（=213px 内区）约容纳正文 8 行或"带小标题的条目"7 行。**先算容量再填内容**，超容量砍内容，不缩字号。

## §11 验收四门禁 + 整页 12 问 + 返工顺序

**四道门禁（逐册）**：
1. **蓝图门禁**：连读全部页标题应构成完整叙事弧线（每页 adds 非空）。
2. **缩略图门禁**：整册缩小看节奏——器型多样、明暗交替、无连续同款布局。
3. **最坏页门禁**：每类复看一页——最密的、最大空白的、最复杂图的、来源最多的、结论最强的。
4. **交付门禁**：对照 §4–§10 全部红线逐页过一遍。

**整页 12 问（抽查论证页）**：
① 主证据是否首先进入视线？② 标题判断与图中差异是否同一件事？③ 标题+副标题+收束是否"同一件事的三种说法"且只下一层判断？④ 收束是否唯一？⑤ 密度档位是否与页面职责匹配？⑥ 每块留白有无阅读用途？⑦ 图型是否匹配数据关系（§5）？⑧ 数据契约是否满足（§5/§7）？⑨ 有无触犯 §6 红线？⑩ 图示边是否带语义标注（§8）？⑪ 填充率同排差是否 ≤15pp？⑫ 来源与章节引用是否齐全？

**视觉返工顺序**（不许跳步）：
① 回到主张-证据层查漏（是不是关系没画出来）→ ② 重选/重组展品与阅读路径 → ③ 调主辅比例与空间对齐 → ④ **最后**才动字号、间距、颜色。

**问题分级**：Blocking = 误导性编码 / 证据缺失却下判断；Major = 关系表达错误 / 大块无功能留白 / 层级失守；Minor = 间距与对齐瑕疵。
