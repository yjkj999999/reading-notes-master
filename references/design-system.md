# 设计系统 — 出版级读书笔记视觉规范

> 提炼自 31 份读书笔记语料（约 2,500 页）的实测数据（字体/字号/色板/图片密度均由程序化度量获得）。
> **v2 提示**：通用出版级质感（暖墨/耳语边框/柔影/负字距/护栏）已抽离至 `design-tokens.md`；
> 本文件负责**书籍层选型**（版式/字体/主题色映射）。换肤优先级：design-tokens（勿动）→ 本文件选主题色 → 模板 `:root` 三变量。

## 1. 版式基底

| 版式 | 画布 | 占比 | 适用 |
|---|---|---|---|
| **16:9 横版幻灯片**（主流） | 960×540 pt | 28/29 | 分享、演讲、屏幕阅读 |
| **A4 竖排文档型** | 592×842 pt | 1/29（考试脑科学） | 打印、深读、章节化结构笔记 |
| 720×405 pt 变体 | 720×405 pt | 少数（金线/公司理财） | 等效 16:9，字号整体缩小 |

- 页数带：22–270 页；精华版建议 **30–60 页**，深度版 80–140 页。
- PPT 导出 PDF 的字号读数 ×10（24pt 正文 → PDF 内 240），换算见下表。

## 2. 字体系统

### 2.1 中文主字体（实测覆盖率从高到低）
| 字体 | 字重 | 气质 | 语料样本 |
|---|---|---|---|
| **微软雅黑**（首选） | Regular / Bold / Light | 现代商务、屏幕友好 | 几乎全部 PDF 样本 |
| 宋体 SimSun / 华文中宋 | Regular | 人文、书卷 | 传统/人文类 |
| 黑体 SimHei / 华文细黑 | Regular | 醒目标题 | 标题层 |
| 楷体 STKaiti | Regular | 书法感、古典 | 孙子兵法（拆字封面） |
| 汉仪书宋 HYShuSongErKW | — | 出版级正文书感 | 金线 |
| 阿里巴巴普惠体 AlibabaPuHuiTi | 多字重 | 互联网品牌感 | 情绪价值 |

**规则**：一本笔记中文主字体 ≤2 种（标题 Bold + 正文 Regular/Light 同族最稳）；人文/历史类可加楷体点缀（≤10% 篇幅）。

### 2.2 西文配对
Arial / Arial Black / Calibri（无衬线商务）· Palatino-Roman / BritannicBold / HelveticaNeue（衬线与几何，人文与高端）· Wingdings（装饰符号）。

### 2.3 字号阶梯（16:9 幻灯片制，pt）
| 层级 | 字号 | 用途 | 实测锚点 |
|---|---|---|---|
| 封面主标 | **64–120** | 书名 | 浪潮之巅 96/72pt 档 |
| 封面副标 | 24–40 | 定位语/卖点（≤3 行） | 周期"人人都需弄懂自己位置的一本书" |
| 篇章页 | **42–56** | PART 名 | 浪潮之巅篇章分隔 |
| 页标题 | **34–40** | 内容页标题 | 全库众数 |
| 副标/栏目标题 | 26–32 | 卡片题、栏目题 | 双栏页 |
| 正文 | **20–24** | 要点、叙述 | 全库众数 |
| 注释/页脚 | 14–18 | 出处、页码、引流语 | 美股70年页脚 |

- 720×405 变体等效阶梯：正文 12–15 / 页标题 18–24 / 封面 44–60。
- A4 文档型：正文 12pt、节标 36pt、行距 1.5–1.75。
- 幻灯片制行距 1.3–1.5，段间距 ≥0.5em，页边距 ≥48pt。

## 3. 色彩系统

### 3.1 结构配比（实测）
白/浅底占比 34–70%（均值≈50%）→ **白底主导 + 主题色块 + 强调点缀**；每页色彩 ≤3 族。

```
底色 白系 ~50–65%  |  主题色 20–35%（标题带、色块、篇章页）  |  强调色 ≤10%（高亮、编号、金句）
```

### 3.3 收尾规则
- 篇章分隔页 = 主题色整页（或 70% 色块）+ 大字白/金。
- 金句页 = 白底 + 超大引号（主题色 10% 透明度）+ 居中金句。

## 4. 图像与装饰

- **图片密度 0.07–1.0，多数 >0.6**：每页至少一个视觉锚点（图表/照片/色块/大编号），纯文字页 ≤20%。
- 图片类型：作者照片、书封、公司 LOGO/产品图、场景插图、行情图表截图。
- 装饰元素：超大编号（01/NO1）、色带、细线分隔、Wingdings 符号、引号。
- 图表配色：主题色为基 + 强调色 1 种 + 灰阶，禁用彩虹色。

## 5. 页面框架件

```
┌────────────────────────────────────┐
│ 页眉带（~40pt）: 笔记名/logo/章节名      │ ← 美股70年"无风镜"、考试脑科学"John笔记"
├────────────────────────────────────┤
│                                    │
│        内容区（安全边距 ≥48pt）          │
│                                    │
├────────────────────────────────────┤
│ 页脚带（~28pt）: 页码 | 引流/版权语       │ ← "入分享群""版权归起点书院"（可选）
└────────────────────────────────────┘
```

- 页码格式：`第 n 页 / 共 N 页` 或 `n / N`。
- 引流/版权语为自媒体场景可选件；企业内部分发版应去除。
