## §2 五点定义（用户原话 + 梁宁定义双轨）

- **痛点 = 不得不解决的麻烦**：用户害怕恐惧的点（梁宁：用户用"怕"做选择；不被满足只是难受，不能拿难受当痛点）。
  六怕词签：怕老 / 怕死 / 怕穷 / 怕丑 / 怕孤独 / 怕没希望。
- **痒点 = 心里长草的欲望**：痛点基础上的增值服务（梁宁：满足虚拟自我，"你卖的是一种生活方式"）。
- **爽点 = 立竿见影的舒服**：即时性爽感，兴奋型需求（梁宁：即时满足；俞军六字答卷"搜得到，能下载"）。
- **燃点 = 一群人的热血**：集体记忆、家国叙事、情感共鸣。
- **爆点 = 忍不住转发的新鲜感**：社交货币，让产品自己会说话。

权重树：痛点=根（缺失则一切价值不存在）→ 痒点=叶（缺失则附属价值变少）→ 爽点=花（缺失则少眼前一亮，总体价值尚在）→ 燃点=火（引爆）→ 爆点=风（扩散）。
公式：**爆品 = 痛点 × 痒点 × 爽点 ＋ 燃点 ＋ 爆点**。

## §4 五点×四法观察矩阵（版块二，直接落 5×4 大表）

| 开关 | 目标 | 四法 | 去哪看 | 命中信号 |
|---|---|---|---|---|
| 痛点 | 找 | 逛差评区 / 盯重复投诉 / 客户聊天 / 己当用户 | 差评区·客服记录·排队 | 「要是……就好了」 |
| 痒点 | 挖（愿多花钱） | 看热门种草 / 盯高端需求 / 学奢侈品思路 / 抓季节情绪 | 收藏夹·种草笔记 | 「别人的生活」 |

| 燃点 | 引（为情怀买单） | 绑共同记忆 / 借社会情绪 / 讲价值观 / 造小仪式 | 阅兵·老照片·同学会 | 「我们那时候」 |
| 爆点 | 做（自己会说话） | 做视觉冲击 / 玩反差感 / 蹭轻热点 / 留互动空间 | 朋友圈·打卡墙 | 「快看这个」 |

观察五问（不是靠猜，是靠观察）：抱怨什么（痛点）/ 羡慕什么（痒点）/ 喜欢什么即时反馈（爽点）/ 愿为什么情绪买单（燃点）/ 对什么好奇（爆点）。

## §5 三感三力（右脑能力，常作开篇理论页）

| 力 | 内涵解读 |
|---|---|
| 设计感 | 追求美观、新颖和意义，不止于功能，关乎情感体验与价值认同 |
| 娱乐感 | 幽默感，把快乐与游戏精神融入工作，激发创造力与团队活力 |
| 意义感 | 超越物质追求，嫁接宏大目标，找到深层动力与自我实现 |
| 故事力 | 把信息置于情感化场景叙述，有感染力与记忆点 |
| 交响力 | 综观全局，跨界组合不相关概念，实现系统性创新 |
| 共情力 | 设身处地理解他人情绪，建立深层次连接 |

数据锚点：设计投入每 +1% → 销售利润平均 +4%（平克《全新思维》）；华为伊尔-2 广告"没有伤痕累累，哪来皮糙肉厚"。
器型：六边形雷达 SVG（六顶点同满）+ 大数字卡 +4%。

## §6 新增器型（超出 chart-catalog 10 类，情绪营销类实战验证）

1. **拨杆开关面板**（封面）：CSS 自绘竖向轨道+圆钮，五色各一，ON 态圆钮在顶；面板白底圆角 20 柔影。
2. **五段光谱带**（总览页）：flex 五等分，各段专色底白字，大情绪字（衬线 56px）+开关名+一句定义+序号。
3. **升维阶梯**（痒点页）：四级右向递高色块（淡→专色），底部对齐，高度 58/70/82/94px。
4. **传播环**（爆点页）：SVG 虚线圆 + 5 节点白底圆（r=36）+ marker 箭头弧段（每段 60°，sweep=1），中心实心圆。
5. **权重树**（公式页）：SVG 简笔树（树冠三圆+树干+根三曲线）+ 右侧五行图例（色点+名称+一句权重）。
6. **六怕词签行**（痛点页）：六枚同色系淡底胶囊 + 尾注"六怕，皆是痛点"。

## §7 认知金句库（收尾页/封底金句带）

- 钱是"谋"来的，不是"挣"来的——谋局比埋头做事更值钱。
- 财富本质是认知变现：你永远赚不到认知外的钱；靠运气赚的，迟早靠实力亏掉。
- 做企业要懂政策，就像农民种地要看天——政策就是企业的"天"。
- 大众为情绪和故事买单，而非冰冷的真相。
- 趋势就是天道，顺势者昌——把五点练成营销绝活，成交了无痕迹，客户会主动成交。
- 梁宁："没有恐惧这条疯狗追着，没有爽点这种满足感喂养，一定是不痛不痒的产品。"
