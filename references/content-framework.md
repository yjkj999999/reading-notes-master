# 内容框架 — 页面模块与叙事原型

> 提炼自 31 份语料的结构共性：9 个标准页面模块 + 6 大叙事原型 + 结构化八模块模板。

## 1. 九大标准页面模块（页面序列积木）

| # | 模块 | 必备要素 | 实测样本 |
|---|---|---|---|
| 1 | **封面页** | 书名大字(64–120pt) + 作者 + **笔记作者署名** + 定位语/卖点(≤3 行)；可选联名背书 | 金线"麦肯锡 X 冯唐"；周期"人人都需弄懂自己位置的一本书" |
| 2 | **作者简介页** | 照片 + 头衔 + **履历时间线**（年份→事件，3–6 段） | 金线(1998协和→2021不二堂)；周期(橡树资本) |
| 3 | **背书推荐页** | 4–6 位实名推荐人（头像/姓名/头衔/≤60字推荐语）；或试读评论、豆瓣评分引用 | 周期(达利欧/巴菲特/芒格/冈德拉奇+缪建民/屠光绍/张晖)；极简市场营销(江南春/袁岳/王赛/蒋青云/刘润)；公司价值分析引用"豆瓣评分9.0" |
| 4 | **为什么读它页** | 核心问题 2–3 个 / 大师名字矩阵 / 适读人群标签 / 卖点 bullet（数字量化优先） | 周期(本书的核心问题1/2)；极简市场营销(科特勒/麦卡锡/特劳特…矩阵+"20多年超50亿元市场花费");丰田一页纸(适读人群) |
| 5 | **目录页** | **CONTENTS** + 编号 01/02/03（3–5 个 PART，每条带副题） | 全库 90%+ 样本标配 |
| 6 | **篇章分隔页** | PART 编号 + 篇章名 + **诗意副题** | 浪潮之巅 4 篇章"那些定律并不深奥但极为有用" |
| 7 | **内容页** | 9 种子版式见 chart-catalog.md | — |
| 8 | **金句强化页** | 超大引号 + 居中金句 + 主题色；或"一句话总结"装置 | 考试脑科学每章金句块；浪潮之巅封底金句 |
| 9 | **收尾页** | 思维导图+反思 / 读后感"我说" / 推荐指数 / Thank you+金句 | 美股70年、周期(思维导图及反思)；孙子兵法("我说"：不要为读书而读书)；浪潮之巅(Thank you) |

**页面序列公式**：`封面 → 作者简介 → [背书推荐 →] [为什么读它 →] 目录 → (篇章分隔 → 内容页×n → 金句页)×PART → 收尾`

## 2. 结构化八模块模板（考试脑科学范式 — 信息密度之王）

每章/每节内容页固定循环以下 8 个模块（A4 文档型或深读版适用）：

```
1. 标题          — 章-节编号 + 问句式标题
2. 一句话总结     — ≤40 字，一句说透本章
3. 大纲          — 编号要点 ≤8 条（每条 ≤30 字）
4. 关键内容      — 编号要点 ≤5 条（每条 ≤50 字，压缩大纲）
5. 金句          — 原文引号摘录 3–5 条
6. 问答          — Q/A 组 3–5 组（考试自测式）
7. 关键词标签    — "标签1""标签2"…（5–8 个）
8. 术语解释      — 编号 ≤5 条（每条 ≤40 字）
```

> 该模板兼顾"大纲/关键内容"双层压缩与"问答/术语"复习功能，是结构化文档型笔记的黄金骨架。

## 3. 六大叙事原型（先选型，再排页面）

| 原型 | 适用书型 | 页面序列 | 代表样本 |
|---|---|---|---|
| **A 叙事演绎型** | 商业史、传记、案例集 | 封面→推荐语→互动引入(小测试)→篇章分隔→定律/公司页(带雅号副标题)→读者感言→封底Thank you+金句 | 浪潮之巅(34页，IBM"蓝色巨人"、英特尔"奔腾的芯") |
| **B 工具方法型** | 方法论、工具书 | 封面→作者→适读人群→核心概念(框架图)→步骤①–⑤→技巧1–3→工作应用→感谢 | 丰田一页纸(Excel1/Logic3框架、绿蓝红三色笔) |
| **C 结构化文档型** | 科普、教科书、备考 | 封面→(前言八模块)→章×八模块→附录 | 考试脑科学(76页A4竖排) |
| **D 数据复盘型** | 行情、数据、年报类 | 封面→作者→本书框架→推荐理由NO1–5→目录→PART分隔→阶段复盘页(大事回顾/经济形势/行情特征三段式)→思维导图及反思 | 美股70年(97页，1948–2018八阶段) |
| **E 背书营销型** | 名家名作、畅销书 | 卖点封面→作者履历→重磅推荐墙(2页)→核心问题→规律/框架提炼→章节展开 | 周期(53页)、极简市场营销(134页)、金线(83页) |
| **F 主题分组型** | 典籍、合集、演讲录 | 书法感拆字封面→作者→概要→主题组页×N(每页3条目×[篇名+论述+中心思想])→"我说"读后感 | 孙子兵法(9页pptx，五组：战略运筹/作战指挥/战场机变/军事地理/特殊战法) |

**选型决策**：
- 有强数据/年表 → D；有强名人背书 → E；有清晰步骤工具 → B；
- 章节多且需自测 → C；故事案例为主 → A；条目可分组提炼 → F。
- 混合书可主原型 + 副原型混排（如 D 的复盘页嵌入 E 的推荐墙）。

## 4. 金句工程

- **密度**：每章 ≥2 条原句金句（带引号），全书金句页 1–3 页。
- **"一句话总结"装置**：金线/极简市场营销/品牌营销100讲/考试脑科学共同使用——每个模块用一句话概括收口，作为最强的记忆钩子。
- **书摘序列**：周期"精彩书摘01–04"编号连载式；可作为独立栏目页。
- **金句页版式**：白底 / 主题色底交替；超大引号装饰；金句 32–48pt 居中；出处小字 14pt。

## 5. 文案规范

- 定位语：≤20 字，动词开头或判断句（"看清现在，看透未来"）。
- 卖点 bullet：≤3 条，数字优先（"10个常用模型、107个本土案例"）。
- 章节副题：诗意化提炼（浪潮之巅式），避免直译目录。
- 读者视角署名：笔记作者名固定出现于封面与页眉（"读书笔记：无风镜""John笔记"）。
